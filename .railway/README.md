# Railway infrastructure

Authoring file: `railway.ts` (Railway Infrastructure as Code).

```bash
railway link                 # once, if this directory is not linked
railway config plan          # preview
railway config apply         # apply after confirmation
railway domain -s docs       # generate a `*.up.railway.app` URL
```

Config as Code (`railway.json` / `railway.toml`) is deprecated. Keep one authoring file here.
