# docs

This is a Tanstack Start application generated with
[Create Fumadocs](https://github.com/fuma-nama/fumadocs).

The docs app uses shadcn's Base UI Dialog as the native backdrop adapter for
the Cue examples. Run `pnpm dlx shadcn@latest add dialog` from this directory
to regenerate the local component when needed.

Run development server:

```bash
npm run dev
# or
pnpm dev
# or
yarn dev
```
