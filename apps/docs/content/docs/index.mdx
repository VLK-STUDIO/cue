`@vlkoss/cue` lets you register a dialog once, then open it from a click handler, a route effect, or another overlay.

## Installation

```npm
npm i @vlkoss/cue
```

### shadcn

If you prefer, install cue from the [shadcn registry](https://ui.shadcn.com/docs/registry) and customize the source in your project. Pick one:

<Tabs items={["URL", "Namespace", "GitHub"]} groupId="shadcn-install" persist>
  <Tab value="URL">

```npm
npx shadcn@latest add https://cue.vlkstudio.com/r/cue.json
```

  </Tab>
  <Tab value="Namespace">

Register the registry once. `{name}` is a URL template the CLI fills with the item name (`cue` → `…/r/cue.json`):

```npm
npx shadcn@latest registry add @cue=https://cue.vlkstudio.com/r/{name}.json
npx shadcn@latest add @cue/cue
```

  </Tab>
  <Tab value="GitHub">

```npm
npx shadcn@latest add mauroerta/cue/cue
```

  </Tab>
</Tabs>

<Callout type="info">
With the registry install, import from your project's `@/lib/cue` path (or whatever
`aliases.lib` resolves to) instead of `@vlkoss/cue`.
</Callout>

## Add the provider

Render `OverlayProvider` once near the root of your app.

```tsx
import { OverlayProvider } from "@vlkoss/cue";

export function App() {
  return (
    <OverlayProvider>
      <Page />
    </OverlayProvider>
  );
}
```

## Create an overlay

Define the overlay next to the component it renders. Spread `OverlayProps` (`open`, `onOpenChange`) onto your dialog so Escape and backdrop clicks still close it.

```tsx
import { createOverlay, type OverlayProps } from "@vlkoss/cue";
import { Dialog } from "./dialog";

export const settingsDialog = createOverlay((props: OverlayProps) => (
  <Dialog {...props} title="Settings">
    <button type="button" onClick={() => settingsDialog.close()}>
      Close
    </button>
  </Dialog>
));
```

## Open it

Call `open()` from anywhere. No local `useState`.

```tsx
settingsDialog.open();
```

Works with any component that accepts `open` and `onOpenChange`: Radix Dialog, Base UI, vaul, or your own.
