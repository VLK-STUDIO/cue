title: Default
description: Create a Cue environment and open an overlay with no props.
---

Create the Cue environment once, then define an overlay from it:

<Demo>
  <DemoPreview>
    <DefaultDemo />
  </DemoPreview>

```tsx
import { createCue } from "@vlkoss/cue";
import { Dialog } from "./dialog";

export const cue = createCue();

export const settingsDialog = cue.createOverlay((_props, ctx) => (
  <Dialog open={ctx.open} onOpenChange={ctx.onOpenChange} title="Settings">
    <p>No local useState required.</p>
    <button type="button" onClick={() => ctx.close()}>
      Close
    </button>
  </Dialog>
));

settingsDialog.open();
```

</Demo>

The same `cue` instance supplies `cue.OverlayProvider` near the app root. `open()` returns the close function for the new instance. `closeAll()` closes every live instance of this overlay definition.
