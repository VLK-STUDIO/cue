title: Default
description: Create a Cue environment and open an overlay with no props.
---

Create the Cue environment once, then define an overlay from it:

<Demo>
  <DemoPreview>
    <DefaultDemo />
  </DemoPreview>

```tsx
import { cue } from "@/components/cue";
import { Button } from "@/components/ui/button";

export const settingsDialog = cue.createOverlay((_props, ctx) => {
  const components = ctx.components;

  return (
    <components.wrapper open={ctx.open} onOpenChange={ctx.onOpenChange}>
      <components.content>
        <components.title>Settings</components.title>
        <components.description>No local useState required.</components.description>
        <components.footer>
          <Button variant="outline" onClick={() => ctx.close()}>
            Close
          </Button>
        </components.footer>
      </components.content>
    </components.wrapper>
  );
});

settingsDialog.open();
```

</Demo>

The same `cue` instance supplies `cue.OverlayProvider` near the app root. `open()` returns the close function for the new instance. `closeAll()` closes every live instance of this overlay definition.
