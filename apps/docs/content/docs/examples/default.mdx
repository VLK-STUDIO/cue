---

Create the Cue environment once, then define an overlay from it:

<Demo>
  <DemoPreview>
    <DefaultDemo />
  </DemoPreview>

```tsx
import { cue } from "@/components/cue";
import { Button } from "@/components/ui/button";
import { Dialog } from "@/components/ui/dialog";

export const settingsDialog = cue.createOverlay((_props, ctx) => {
  const {
    content: Content,
    description: Description,
    footer: Footer,
    title: Title,
  } = ctx.components;

  return (
    <Dialog open={ctx.open} onOpenChange={ctx.onOpenChange}>
      <Content>
        <Title>Settings</Title>
        <Description>No local useState required.</Description>
        <Footer>
          <Button variant="outline" onClick={() => ctx.close()}>
            Close
          </Button>
        </Footer>
      </Content>
    </Dialog>
  );
});

settingsDialog.open();
```

</Demo>

The same `cue` instance supplies `cue.OverlayProvider` near the app root. `open()` returns the close function for the new instance. `closeAll()` closes every live instance of this overlay definition.
