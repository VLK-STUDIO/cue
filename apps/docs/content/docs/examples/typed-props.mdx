---
title: Typed props
description: Pass application data into an overlay when you open it.
---

Give `cue.createOverlay()` a props generic. Required keys must be passed to `open()`; if every key is optional, bare `open()` is allowed.

<Demo>
  <DemoPreview>
    <TypedPropsDemo />
  </DemoPreview>

```tsx
export const confirmDeleteDialog = cue.createOverlay<{
  organizationName: string;
}>((props, ctx) => (
  <Dialog
    open={ctx.open}
    onOpenChange={ctx.onOpenChange}
    title={`Delete ${props.organizationName}?`}
  >
    <button type="button" onClick={() => ctx.close()}>
      Cancel
    </button>
  </Dialog>
));

confirmDeleteDialog.open({
  organizationName: "Helios",
});
```

</Demo>

The props generic describes only values supplied at open time. `open`, `onOpenChange`, `close`, and `components` come from the second callback argument.
