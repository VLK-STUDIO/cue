---
title: openAsync
description: Wait for an overlay result with a Promise.
---

`openAsync` opens a new instance and returns a Promise. Declare a result type as the second generic on `createOverlay`. Dismiss (Escape, backdrop, bare `close()`) resolves `undefined`.

<Demo>
  <DemoPreview>
    <OpenAsyncDemo />
  </DemoPreview>

```tsx
const confirmed = await asyncConfirmDialog.openAsync({
  message: "Archive this project?",
});

if (confirmed) {
  // archive
}
```

</Demo>

## Example

```tsx
export const asyncConfirmDialog = createOverlay<{ message: string }, boolean>((props) => (
  <Dialog {...props} title="Confirm">
    <button type="button" onClick={() => props.close({ result: false })}>
      Cancel
    </button>
    <button type="button" onClick={() => props.close({ result: true })}>
      Confirm
    </button>
  </Dialog>
));

const confirmed = await asyncConfirmDialog.openAsync({
  message: "Archive this project?",
});
// Promise<boolean | undefined>
```

Any result type works:

```tsx
createOverlay<{ title: string }, "one" | "two" | "three">((props) => (
  <button type="button" onClick={() => props.close({ result: "two" })}>
    Two
  </button>
));

const choice = await dialog.openAsync({ title: "Pick" });
// Promise<"one" | "two" | "three" | undefined>
```

With no result generic, `openAsync` is `Promise<undefined>`: wait until the instance closes, no payload.
