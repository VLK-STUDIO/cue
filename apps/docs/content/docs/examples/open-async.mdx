---
title: openAsync
description: Wait for an overlay result with a Promise.
---

`openAsync()` opens a new instance and returns a Promise. Declare the result type as the second generic on `cue.createOverlay()`. Dismissal, Escape, and a bare `close()` resolve `undefined`.

<Demo>
  <DemoPreview>
    <OpenAsyncDemo />
  </DemoPreview>

```tsx
const confirmed = await asyncConfirmDialog.openAsync({
  message: "Archive this project?",
});

if (confirmed) {
  // archive
}
```

</Demo>

## Example

```tsx
export const asyncConfirmDialog = cue.createOverlay<{ message: string }, boolean>((props, ctx) => (
  <Dialog open={ctx.open} onOpenChange={ctx.onOpenChange} title="Confirm">
    <p>{props.message}</p>
    <button type="button" onClick={() => ctx.close({ result: false })}>
      Cancel
    </button>
    <button type="button" onClick={() => ctx.close({ result: true })}>
      Confirm
    </button>
  </Dialog>
));

const confirmed = await asyncConfirmDialog.openAsync({
  message: "Archive this project?",
});
// Promise<boolean | undefined>
```

Any result type works:

```tsx
const dialog = cue.createOverlay<{ title: string }, "one" | "two" | "three">((_props, ctx) => (
  <button type="button" onClick={() => ctx.close({ result: "two" })}>
    Two
  </button>
));

const choice = await dialog.openAsync({ title: "Pick" });
// Promise<"one" | "two" | "three" | undefined>
```
